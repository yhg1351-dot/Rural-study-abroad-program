# 경남형 농어촌유학

경남형 농어촌유학 웹사이트 저장소입니다.

## 경남형 농어촌유학이란

타시도의 도시 학생들이 경남의 농어촌 작은학교에서 일정 기간 생활하며 지역의 자연·문화와 학교의 특색 있는 교육과정을 경험하고, 유학생과 재학생이 함께 성장하는 도농 상생 교육프로그램입니다.

## 폴더 구성

| 폴더 | 용도 |
| --- | --- |
| `index.html` | 사이트 본문 (모든 페이지가 이 파일 하나에 들어 있음) |
| `assets/css/style.css` | 디자인 |
| `assets/js/main.js` | 메뉴와 페이지 전환 |
| `docs/` | 사이트 메뉴 구성, 콘텐츠 기획 등 기획 문서 |
| `assets/images/` | 사이트에 쓰는 사진·이미지 (공개해도 되는 것만) |

## 사이트 구조 (초안)

별도 설치나 빌드 없이 GitHub Pages로 바로 올릴 수 있는 정적 사이트입니다. 주소 뒤의 `#about`, `#apply` 같은 표시로 페이지를 바꿉니다.

| 메뉴 | 페이지 |
| --- | --- |
| 소개 | 경남 농어촌유학이란 (`#about`), 유학 유형 (`#types`), 유학 학교 (`#schools`) |
| 모집·신청 | 신청 안내 (`#apply`), 연장·중도 종료 (`#change`), 공지사항 (`#notice`), 자주 묻는 질문 (`#faq`) |
| 학교생활 | 학교생활 안내 (`#life`) |
| 함께 성장 | 함께 성장 이야기 (`#together`) |

노란 점선 상자(`class="todo"`)는 아직 자료가 없어 비워 둔 자리입니다. 내 컴퓨터에서 보려면 `index.html`을 브라우저로 열면 됩니다.

## 주의사항

이 저장소는 공개(Public) 저장소입니다. 커밋 기록까지 누구나 볼 수 있고, 한 번 올린 파일은 삭제해도 기록에 남습니다. 다음 자료는 올리지 마세요.

- 학생·학부모 이름, 연락처, 신청서 등 개인정보
- 공개 전 내부 계획 문서, 예산 자료
- API 키, 비밀번호 등 인증 정보
- 초상권 동의를 받지 않은 학생 사진
